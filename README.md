Genshin Original Resin Counter is fun **android** project application that tells you when will your resins be ready to use in terms of time. 
It mimics the original Genshin Impact timer that's located on the map interface.
The project was made for fun.

# Features
* It WILL ask you for notification since i was able to implement a little notification when the timer goes to 0 that tells you when the resins are ready to use.
